# StableAMD Image-to-SVG v1 — RX 6950 XT Acceptance Worksheet

Date: 2026-09-22
Target: Windows + AMD Radeon RX 6950 XT 16 GiB (gfx1030)
Branch: feat/stableamd-v0.3
Status: implementation in progress; physical acceptance pending

## Required automated gates

- request validation and unknown-field rejection
- managed Upload / Gallery / Current source resolution
- arbitrary filesystem path refusal
- EXIF orientation and alpha preservation
- Preserve / Auto-trim / Manual crop
- border-connected background removal
- Artwork / Photo Direct / Stylized Preserve deterministic preprocessing
- Creative capability gating and Krea adapter
- CPU-local vector job serialization
- Krea GPU lock only during Creative preprocessing
- VTracer / Clean SVG sanitizer / resvg preview reuse
- Image-to-SVG history metadata and ownership-safe deletion
- Gallery Convert to SVG
- Current Generate/Image Edit Convert to SVG
- Image-to-SVG Reuse with retained source and missing source
- responsive Vector workspace and Advanced disclosure
- isolated import / package coverage

## Physical checklist

### 1. Artwork — transparent source
Source: transparent PNG logo or flat artwork.

Settings:
- Mode: Artwork
- Detail: Medium
- Colors: Auto
- Background: Preserve
- Crop: Preserve

Verify:
- alpha survives;
- hard edges remain coherent;
- no unexpected background is introduced;
- SVG preview and source are valid.

### 2. Artwork — opaque flat illustration
Source: opaque flat illustration with exterior margin.

Settings:
- Mode: Artwork
- Crop: Auto-trim
- Background: Transparent

Verify:
- exterior margin is removed;
- enclosed same-colored subject regions survive;
- canvas is cropped to the subject;
- SVG remains Clean SVG compliant.

### 3. Photo — Direct
Source: ordinary photograph.

Settings:
- Photo / Direct
- Medium
- Colors: 8
- Background: Preserve
- Crop: Preserve

Verify:
- deterministic local path completes without Krea;
- composition is retained;
- result is a simplified vector interpretation rather than a generated reinterpretation.

### 4. Photo — Stylized / Preserve
Use the same photograph.

Settings:
- Photo / Stylized
- Preserve
- Medium
- Colors: 8

Verify:
- stronger posterization/simplification than Direct;
- source composition, pose and subject placement remain stable;
- no Krea dependency is required.

### 5. Photo — Stylized / Creative
Use the same photograph.

Settings:
- Photo / Stylized
- Creative
- Medium
- Colors: 8

Verify:
- Krea Image Edit is used only for the Creative preprocessing stage;
- Krea runtime is released before VTracer;
- flat/vector-like raster is produced before tracing;
- child Creative raster remains traceable if a later stage fails.

### 6. Manual crop
Use a source with substantial margins.

Verify:
- crop editor displays source;
- X/Y/Width/Height are bounded;
- crop cannot leave the decoded image;
- changing source dimensions does not silently reuse a stale crop.

### 7. Local-only operation with Krea unavailable
Temporarily make Krea Image Edit unavailable.

Verify:
- Artwork, Direct and Preserve remain usable;
- Creative is explicitly disabled/rejected;
- no fallback silently invokes another generative provider.

### 8. Gallery handoff
From a raster Gallery card:
- Convert to SVG
- verify Image-to-SVG workspace opens with that source selected.

### 9. Current-result handoff
Generate or Image Edit an image.
- use Convert to SVG / Use current image;
- verify no download/re-upload is required.

### 10. SVG lifecycle
Verify:
- Download SVG
- View source
- Reuse
- Delete

For Delete:
- Image-to-SVG-owned intermediates may be removed;
- Gallery/current source must remain intact.

### 11. Provider regression
After Creative:
- run normal Krea Image Edit;
- run normal Z-Image generation.

Verify no stale GPU/VRAM/runtime state remains.

### 12. Repeat-run stability
Run at least three Image-to-SVG jobs across local modes, then one Creative job if available.

Record:
- wall-clock time;
- SVG path/node counts;
- preview success;
- failures by stage;
- whether subsequent Krea/Z-Image runs remain healthy.

## Acceptance rule

Image-to-SVG v1 becomes target-accepted only after the required physical checklist passes on the RX 6950 XT. Automated GREEN alone is not physical acceptance.
