# StableAMD v0.3 — Krea 2 LoRA target test

This gate verifies the official Krea 2 Turbo LoRA path on the target RX 6950 XT 16 GiB machine before it is recorded as target-accepted.

## Implementation

The current Krea 2 Turbo provider keeps its accepted base graph and inserts an ordered `LoraLoaderModelOnly` chain between `UNETLoader` and `KSampler`. The Qwen3-VL text encoder is unchanged and LoRA CLIP strength is fixed to zero.

This matches the official Comfy-Org Krea 2 Turbo workflow, which documents optional style LoRA loading through `LoraLoaderModelOnly` and recommends the published style adapters under `Comfy-Org/Krea-2/loras`.

StableAMD keeps the accepted Turbo defaults:

```text
8 steps / CFG 1 / Euler / simple
```

```text
.runtime/stableamd/models/loras/krea/krea2_darkbrush.safetensors
```

```powershell
curl.exe -L --fail --retry 5 --retry-delay 2 --retry-all-errors `

  "https://huggingface.co/Comfy-Org/Krea-2/resolve/main/loras/krea2_darkbrush.safetensors"
Get-FileHash ".runtime\stableamd\models\loras\krea\krea2_darkbrush.safetensors" -Algorithm SHA256
```

After the file is verified, restart StableAMD so ComfyUI refreshes the LoRA list.

## Acceptance run

1. Select `Krea 2 Turbo (FP8)`.
2. Keep the normal 1024-class Turbo preset and `8 / CFG 1 / Euler / simple`.
3. Add `krea/krea2_darkbrush.safetensors` to the LoRA stack with strength `1.0`.
4. Use a prompt that clearly includes the official trigger phrase, for example `portrait of an astronaut, monochrome ink wash style`.
5. Generate once with the LoRA and once with the same seed/prompt with the LoRA disabled so the style effect is obvious.
6. Run `Upscale after` once on a successful LoRA result.
7. Use Gallery `Reuse settings` and confirm the Krea LoRA stack is restored.

Capture the backend log if the FP8 diffusion model needs an unexpected dequantization/requantization allocation or fails from host/VRAM pressure. Do not change the accepted Krea base profile pre-emptively; first measure the real target behavior.

## Acceptance criteria

- `LoraLoaderModelOnly` is accepted by the pinned ComfyUI graph;
- generation completes on RX 6950 XT with the official FP8 Krea 2 package;
- the adapter produces a visible style change at the expected trigger/strength;
- Gallery history preserves the LoRA stack and Reuse restores it;
- `Upscale after` still succeeds;
- a normal Krea 2 generation without LoRA still succeeds immediately afterwards.
