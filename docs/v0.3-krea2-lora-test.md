# StableAMD v0.3 — Krea 2 LoRA target test

Status: **target-accepted on RX 6950 XT / 16 GiB (2026-09-15)**.

The target run confirmed the official Krea 2 Turbo model-only LoRA path with `krea2_darkbrush.safetensors` at strength `1.0`. The adapter produced the expected visible style effect and normal Krea 2 generation remained usable afterwards.

## Implementation

The current Krea 2 Turbo provider keeps its accepted base graph and inserts an ordered `LoraLoaderModelOnly` chain between `UNETLoader` and `KSampler`. The Qwen3-VL text encoder is unchanged and LoRA CLIP strength is fixed to zero.

This matches the official Comfy-Org Krea 2 Turbo workflow, which documents optional style LoRA loading through `LoraLoaderModelOnly` and recommends the published style adapters under `Comfy-Org/Krea-2/loras`.

StableAMD keeps the accepted Turbo defaults:

```text
8 steps / CFG 1 / Euler / simple
```
