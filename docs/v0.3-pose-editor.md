# StableAMD v0.3 — Pose library & interactive editor

Last updated: 2026-09-15

## Product goal

Pose control must not require users to prepare OpenPose maps in another application.

For both **Z-Image Turbo** and **Krea 2 Turbo**, StableAMD now supports three input paths:

1. upload an existing OpenPose/DWPose map;
2. choose a curated image template from the built-in Pose Library;
3. build or adjust a pose in the interactive editor.

A normal photograph remains optional. Inside the editor it is used only as a translucent alignment overlay and is never baked into the exported OpenPose control map.

Templates are not silently bundled into the application. The browser shows their pinned raw GitHub images and downloads the selected PNG only when the user chooses it.

## Interactive editor

The editor uses the standard 18-joint body map and supports:

- drag-to-move body joints;
- editable upstream preset variants;
- mirror;
- reset;
- optional reference-photo overlay with opacity;
- PNG download;
- `Use edited pose`, which places the generated map directly into the current Control guidance request.

The reference photo is never part of the final control map.

## Provider routes

### Krea 2 Turbo

The existing Krea 2 OpenPose path remains:

```text
OpenPose map
  -> ImageScale
  -> TextEncodeKrea2OstrisEdit
  -> Krea2OstrisEditModelPatch
  -> LoraLoaderModelOnly(krea2_turbo_openpose_controlnet)
  -> KSampler
```

The Pose Library and editor only change where the OpenPose map comes from.

### Z-Image Turbo

Alibaba PAI Union 2.1 is a union model supporting multiple prepared control-map types, including Pose.

StableAMD therefore adds a direct prepared-pose path beside the existing Canny preprocessor path:

```text
OpenPose map
  -> ImageScale(nearest-exact)
  -> ZImageFunControlnet + Union 2.1 Lite
  -> ModelSamplingAuraFlow
  -> KSampler
```

No Canny preprocessing is applied to a prepared pose map.

## Target acceptance

### Z-Image pose

1. Select Z-Image Turbo.
2. Enable Control guidance -> OpenPose map.
3. Open Pose templates and select one preset.
4. Generate at strength `0.9`.
5. Confirm the output follows the selected body pose.
6. Repeat with Interactive pose editor and move at least one arm.
7. Confirm the changed output follows the edited arm position.
8. Run ordinary Z-Image txt2img immediately afterwards.

### Krea 2 pose

1. Ensure the curated Krea 2 OpenPose dependency is installed.
2. Select Krea 2 Turbo.
3. Enable Control guidance -> OpenPose map.
4. Select a template without uploading a file.
5. Generate at strength `0.85`.
6. Repeat with an editor preset and manual adjustment.
7. Confirm ordinary Krea 2 txt2img still works immediately afterwards.
